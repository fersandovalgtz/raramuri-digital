## Qué es Rarámuri Digital

**Rarámuri Digital** es una infraestructura de investigación que publica y transforma datos lexicográficos rarámuri–español como objetos **trazables, versionados, citables, interoperables y reproducibles**. El proyecto distingue cuidadosamente la evidencia documental, la representación de trabajo, la normalización computacional, los productos derivados y la validación lingüística.

No es una norma ortográfica ni una autoridad sobre el conjunto de variedades rarámuri. La disponibilidad técnica del recurso tampoco equivale a validación lingüística o comunitaria. Las formas y análisis deben interpretarse de acuerdo con su procedencia y estado.

## Kenneth Simon Hilton y la fuente de Samachique

La principal referencia lexicográfica histórica asociada con el proyecto es **Kenneth Simon Hilton**, registrado también en catálogos como Kenneth S. Hilton y K. Simón Hilton. Su *Diccionario tarahumara de Samachique, Chihuahua, México* apareció en **1993** como edición especial corregida y actualizada del Instituto Lingüístico de Verano. El registro archivístico describe **viii + 146 páginas**, aproximadamente **2,500 entradas**, secciones tarahumara–español y español–tarahumara, categorías gramaticales, acepciones, formas derivadas, ejemplos y notas. La lengua se identifica como **tarahumara central**, vinculada con Samachique.

La historia documental es anterior a 1993. El Colegio de México conserva *Tarahumara y español* (1959), compilado por Kenneth Simon Hilton con **Ramón López B. y Emiliano Carrasco T.** como colaboradores. En 2016, SIL México archivó además el *Diccionario tarahumara actualizado* de **Wes Shoemaker**, descrito como una actualización de VIMSA 101 (1993) con cambios ortográficos recientes y estado de borrador sin revisión por pares.

Rarámuri Digital **no confunde esa genealogía bibliográfica con su pipeline de producción**. `SRC-01` identifica Hilton 1993 como fuente de referencia y cotejo; `SRC-02` identifica el PDF estructurado de trabajo realmente consumido por el script de extracción. Mientras la identidad de edición de `SRC-02` no se demuestre documentalmente, el dataset no se presenta como una transcripción directa de Hilton 1993.

## Reproducibilidad

Requiere Node.js 22.13 o posterior.

```bash
npm install
npm run data:exports
npm run data:quality
npm run validate
npm run dev
```

La CI no se limita a compilar el sitio: comprueba determinismo de capas derivadas, valida CLDF, contrasta TEI Lex-0 contra el esquema oficial, regenera calidad, ejecuta auditorías del corpus y verifica exportaciones reproducibles. Véase [`.github/workflows/validate.yml`](.github/workflows/validate.yml).

## Estado editorial

- **Publicación:** autorizada para difusión.
- **Transcripción/estructuración:** trazable por documento y página.
- **Validación automática:** activa para integridad, formatos y reproducibilidad.
- **Validación lingüística:** pendiente.
- **Validación comunitaria:** no debe presumirse a partir de la publicación técnica.

La autorización de difusión no equivale a validación lingüística. Las correcciones deben conservar el identificador de entrada y la procedencia documental.

## 🧭 Derechos lingüísticos y gobernanza

Los pueblos indígenas tienen derecho a preservar, revitalizar, utilizar, desarrollar y transmitir sus lenguas a las generaciones futuras. Este derecho está reconocido por el [artículo 13 de la Declaración de las Naciones Unidas sobre los Derechos de los Pueblos Indígenas](https://digitallibrary.un.org/record/606782?ln=es) y por la [Ley General de Derechos Lingüísticos de los Pueblos Indígenas](https://www.diputados.gob.mx/LeyesBiblio/pdf/LGDLPI.pdf) en México.

Esta infraestructura busca apoyar la documentación, consulta y enseñanza del rarámuri. No sustituye la autoridad lingüística, cultural ni política de las comunidades y personas hablantes. La reutilización debe conservar atribución y procedencia, evitar apropiación y descontextualización, respetar decisiones y restricciones comunitarias y promover participación efectiva en la validación, corrección y gobernanza del corpus.
