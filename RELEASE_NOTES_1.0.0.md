# Rarámuri Digital 1.0.0 — Primera publicación científica

**Fecha de publicación del conjunto de datos:** 21 de julio de 2026  
**DOI:** [10.5281/zenodo.21483353](https://doi.org/10.5281/zenodo.21483353)  
**Plataforma operativa:** 3.1.0

## Resumen

Primera publicación científica de Rarámuri Digital, una infraestructura lexicográfica rarámuri–español para investigación, enseñanza, humanidades digitales y desarrollo de aplicaciones.

## Contenido de la versión

- 2,581 entradas lexicográficas con identificadores persistentes.
- 30 productos derivados.
- Exportaciones XML, JSON, CSV, SQL y TEI Lex-0.
- API pública documentada mediante OpenAPI 3.1.
- Esquema y diccionario de datos.
- Informe reproducible de calidad.
- Metadatos CodeMeta y archivo de citación CFF.
- Documentación de gobernanza, derechos lingüísticos, procedencia y contribución.
- Manifiesto técnico con tipo de medio, cobertura, tamaño y suma SHA-256 de cada exportación.

## Estado editorial

- **Publicación:** autorizada para difusión.

# Rarámuri Digital 1.0.0 — Initial scientific release

The first scientific release of Rarámuri Digital, a Rarámuri–Spanish lexicographic infrastructure for research, teaching, digital humanities, and application development.

This version includes 2,581 traceable lexical entries, 30 derived products, XML/JSON/CSV/SQL/TEI Lex-0 exports, a public OpenAPI 3.1 API, a reproducible quality report, CodeMeta and CFF metadata, governance documentation, and a technical manifest with checksums.

**Linguistic validation remains pending.** Authorization for dissemination does not constitute linguistic validation.
